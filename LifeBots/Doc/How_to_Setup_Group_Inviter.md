# How to Setup the LifeBots Group Inviter

## Personal Bot Groups

A LifeBots Full Bot plan is needed to add a Personal Bot Group.

### Add a Personal Bot Group

To add a Personal Bot Group:

- Visit your **LifeBots Dashboard** at [https://lifebots.cloud/dashboard](https://lifebots.cloud/dashboard)
- Click the **Add Group** button
- Click the **Personal Bot Group** pane (requires full bot subscription)
- **Select Your Bot** by clicking on the bot you wish to own this Personal Bot Group
- **Select Groups** (You can select multiple groups for your Personal Bot Group)
- Click **Continue**
- **Select Services**
  - Group Greeter/Inviter checkbox may be disabled at this point, you can add this service later
  - Select all Group services you wish to enable, Group Notices, Group Chat Support, Discord Sync
- Click **Add Groups** button in the lower right corner

You can now view and manage your Personal Bot Groups.

**Note:** Your bot's membership in some groups may need to be elevated to grant
some group permissions in order to be able to manage selected services.

### Manage a Personal Bot Group

Your Personal Bot Groups will now be displayed on your LifeBots Dashboard.

To manage a Personal Bot Group:

- Visit your **LifeBots Dashboard** at [https://lifebots.cloud/dashboard](https://lifebots.cloud/dashboard)
- Click on one of the Personal Bot Groups to manage it
- Depending on which services you have enabled you will see one or more of the following:
  - **Manage Services**
    - Select or Deselect which group services are enabled (**Group Greeter/Inviter** can be enabled here)
  - **API Details**
    - Click API Details and set your Group API Access Code
      - This access code allows external applications to interact with your group through the LifeBots API.
        - Use this code to authenticate API requests for this group
        - Keep this code secure and don't share it publicly
        - You can change this code at any time
        - Code must be between 6-32 characters
      - You can enter the code you wish to use or click the Generate Random Code button (recommended)
      - Click "Copy Code" to copy the code to your clipboard.
      - Store the code securely and do not share it with anyone
      - Click the "Save Access Code" button
      - To view the Groups API documentation visit https://lifebots.cloud/developer and click on Groups
  - **Group Notices**
  - **Group IMs**
  - **Group Chat**
  - **Group Inviter**
    - Configure the Group Inviter
  - **Discord Integration**
    - Connect the Discord Integration with Discord

## Shared Bot Groups

LifeBots Shared Bot Group subscriptions start at L$70 per service weekly.
Use LifeBots systems to provide services to your group without owning a bot.

### Available services

- Group Greeter/Inviter (Under Development)
- Group Notices
- Group Chat Support
- Discord Sync

### Add a Shared Bot Group

- Visit your **LifeBots Dashboard** at [https://lifebots.cloud/dashboard](https://lifebots.cloud/dashboard)
- Click the **Add Group** button
- Click **Shared Bot Group**
- **Select Shared Bot**
  - e.g. select **SyncBot Resident**
- Enter a group name and click the **Search** button
  - Select the group you wish to use, ShareBot will join

## Setup Group Inviter Desk or Screen

- Rez one of the Inviter Objects In-World
  - LifeBots - Desk Inviter
  - LifeBots - Screen Inviter
- Touch the rezzed Inviter
  - This opens a Group Inviter Control dialog menu
- Click the **Select Group** menu button
  - If you see a message "No groups with GroupInviter enabled found ..." then return to the LifeBots website to enable Group Inviter for this land
