# What are the Trigger Talk Add-Ons

You can extend your **LifeBots** bot's capabilities with the growing library of LifeBots specialized add-ons.

**LifeBots** add-ons can be purchased in the **LifeBots Add-On Store** at
[https://lifebots.cloud/store](https://lifebots.cloud/store).

This article describes the **LifeBots Trigger Talk Add-Ons**.

## Overview

The **LifeBots Trigger Talk (Instant Message)** Add-On is a powerful addon for bots that automatically
responds to IMs using customizable rules, keyword matching, friend and teleport logic, and advanced rate limiting.

Similarly, the **LifeBots Trigger Talk (Local Chat)** Add-On automatically responds to local chat using the same
type of customizable rules, keyword matching, friend and teleport logic, and advanced rate limiting.

The **LifeBots Trigger Talk** Add-Ons work with both Lite and Full LifeBots Bot plans.

Purchase the **LifeBots Trigger Talk (Instant Message) Add-On** at [https://lifebots.cloud/store/addon/trigger-talk-instant-message](https://lifebots.cloud/store/addon/trigger-talk-instant-message)

Purchase the **LifeBots Trigger Talk (Local Chat) Add-On** at [https://lifebots.cloud/store/addon/trigger-talk-local-chat](https://lifebots.cloud/store/addon/trigger-talk-local-chat)

## Features

- ✔ Customizable keyword-based autoresponse rules
- ✔ Supports case-insensitive and exact/partial match modes
- ✔ Advanced rate limiting (per-user, global, cooldown)
- ✔ Optional friend requests and teleport offers
- ✔ Event-driven real-time IM handling

## How Trigger Talk Works

The **Trigger Talk** Add-Ons are rule-based response systems.

The bot will respond only when a configured trigger is detected and will reply only with the configured response.

- The bot listens for defined keywords or phrases
- If a trigger matches, the corresponding response is sent
- If no trigger matches, the bot responds only if a default response is configured
- If no default response is set, the bot remains silent

### Key Characteristics

- Strict keyword or phrase matching
- Fixed responses only (no AI generation)
- No personality, memory, or knowledge processing
- Unlimited responses (no LB$ usage)

### Local Chat and IM Support

- **Trigger Talk** is provided as two separate add-ons:
  - One for Local Chat
  - One for Instant Messages (IM)

## Best Use Cases

- Greeting bots
- FAQ or information bots
- Rule reminders
- Simple command-based bots
