# What is the Routine Planner Add-On

You can extend your **LifeBots** bot's capabilities with our growing library of specialized add-ons.
**LifeBots** add-ons can be purchased in the **LifeBots Add-On Store** at
[https://lifebots.cloud/store](https://lifebots.cloud/store).

This article describes the **LifeBots Routine Planner** add-on.

**[NOTE:]** The Routine Planner add-on is only available for LifeBots Full Bots. See the related
articles on the **Pathfinder Add-On** below for LifeBots Lite Bot route management.

## Description

The Routine Planner Advanced Routing System is an add-on for your LifeBots Full Bot.

Routine Planner can be used to create multiple routines with scheduled or keyword-triggered execution.
Perfect for patrols, tours, and interactive behaviors. Build fully automated, interactive bot behaviors
using routines that run on schedules, react to chat/IM triggers, execute actions step-by-step, and even
branch routines based on user responses.

Routine Planner is the automation brain for LifeBots. It lets you build sequences of actions, called routines,
that your bot follows step-by-step. Each step can make the bot talk, walk, teleport, touch objects, wait for
someone to speak, respond to a message, or even switch to another routine.

In simple terms: You can script your bot’s entire behavior without writing code.

## Features

Features of the Routine Planner add-on include:

- ✅ Create fully automated bot routines using step-by-step waypoints
- ✅ Flexible actions: walk, run, turn, teleport, sit, stand, touch objects, play animations, play sounds
- ✅ Chat &amp; IM automation: send messages, wait for replies, react dynamically
- ✅ waitmsg / waitim logic for branching choices and interactive dialogue
- ✅ Switch to another routine mid-flow based on message triggers
- ✅ Scheduled routines with days, times, intervals, and priority systems
- ✅ Trigger-based execution (keywords in chat or IM) with cooldown and whitelist controls
- ✅ All routines fully editable from the dashboard with no scripting required
- ✅ Supports complex flows like NPC behavior, tours, shows, shop bots, event automation
- ✅ Bot-to-Bot interaction support (one bot can trigger another bot’s waitmsg/waitim)

### What Routine Planner Is Most Useful For

- ✔ NPC / RP Characters
  - Walk paths, talk to people, react to messages, perform actions, change animations, etc.
- ✔ Store Bots / Greeters
  - Greet customers, answer keywords, give information, give gifts.
- ✔ Tour Guides
  - Walk to locations, talk about them, wait for the user to respond, branch based on their choice.
- ✔ Showroom / Event Bots
  - Run scheduled routines throughout the day, change outfits, gesture, speak, interact with objects.
- ✔ Club / Venue Bots
  - Dance, emote, respond to DJs/admins, run time-based sequences.
- ✔ Support Bots
  - React to IM keywords, send information, teleport users, handle requests.
- ✔ Auto-Demos
  - Showcase HUDs, objects, tools by interacting with the environment at exact timings.
- ✔ Training / Tutorial Bots
  - Wait for a student to say something → switch routine → guide step-by-step.
- ✔ Patrol / Security Bots
  - Walk paths, scan chat, respond to triggers, switch behavior on alerts.

## Jump to a Routine Example

During a step, the bot can jump to a different routine based on the user’s response.

For example, using a Routine Planner “Tour Guide”:

- Bot says: "Would you like to go inside the store or tour the outside?"
- Bot waits for message:
- (Based on Trigger) → switch to outside tour routine
- (Based on Trigger) → switch to inside store routine
- (Based on Trigger) OR Timeout - Continue routine or switch to another routine

This gives you decision trees and interactive systems.
