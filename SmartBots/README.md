# SmartBots TotalControl

The examples were copied from:
https://www.mysmartbots.com/dev/docs/TotalControl_for_LSL/Examples

- `header.lsl` : header with variables used by all TC scripts
- `auto_responder.lsl` : replies to whoever messages the bot
- `group_inviter.lsl` : invites whoever touches the object to the specified group
- `inventory_giver.lsl` : give out an inventory object to whoever touches the prim
- `payment_inventory_giver.lsl` : give an inventory object to whoever pays the right amount
